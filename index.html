1 · 设定检索话题

两类检索源的区别：全球新闻池由本仓库的 GitHub Actions 每 3 小时在境外服务器抓取境外媒体库（覆盖地缘、经贸、科技、金融、能源、气候等 21 类长期话题），结果写入本仓库的 news-data.json；页面读取的是自己网站里的文件，不跨境、无 CORS 限制、不受境外接口限流影响，也完全不触碰你的 my-rss-blog。RSS 精选源是你订阅站公开的 rss-data.json，只按话题在本机筛选，只读 GET、本机缓存 2 小时并遵循源站 ETag。
只勾「全球新闻池」即可完全不依赖 RSS 检索境外新报道（默认就是如此，清单带「全球新闻池」标签）。新闻池按预设话题定期抓取，冷门或突发话题可能尚未入池，此时可换个检索词或稍后再试（每 3 小时自动更新）；数据生成时间显示在「2 · 报道概览与热度」。点「↻ 刷新数据源」会重新读取新闻池文件，只有勾选了 RSS 时才会额外请求你的订阅站。
