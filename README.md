# Media Insight · 境外媒体舆情检索与总结提炼

一个纯静态的舆情跟踪工具，托管于 GitHub Pages，无需服务器、无需安装。

**固定网址**：https://patfang0105.github.io/media-insight/

## 能做什么

- 输入中文或英文话题，自动译为英文关键词后检索境外媒体报道
- 两类数据源**默认同时开启**：RSS 精选聚合站（你订阅快照里的国际媒体与智库，自带摘要，按话题本机筛选）+ **GDELT 全球媒体库实时检索**（每次检索实时抓取 RSS 之外的新报道，带「实时检索 GDELT」标签）
- 概览显示「实时检索 N 篇 / RSS 精选源 M 篇」来源构成；清单可勾「仅看实时检索」单独核对新内容；GDELT 有 5 秒频率限制，已做节流与重试，失败会如实提示
- 输出报道概览与热度、时间分布、来源排行、关键报道清单
- **检索完成后自动提炼全部命中报道，无需勾选、无需点任何提炼按钮**：逐篇生成中文标题、中文要点、中文摘译，并保留英文原文关键句以便核对
- 同时输出共识线索、立场差异、数字信号与信息局限；报告覆盖本次检索命中的每一篇
- 翻译走 Google gtx（支持长文本、并发），失败自动重试并降级 MyMemory，译文在本机缓存复用；仍失败则保留英文原文并在报告标注失败篇数
- 实时检索条目（GDELT）原文仅提供标题与链接、无公开摘要，报告中只给出中文标题译名并如实标注
- 「仅显示可公开访问」「仅看实时检索」只影响清单显示，不改变提炼范围；可关闭自动提炼，或点「↻ 重新生成全部」手动重跑
- 内置免配置提炼；也可在设置里填 OpenAI 兼容 LLM API 获得更高质量结果，调用失败自动降级
- 付费墙媒体逐条标注访问级别，仅使用其公开摘要，不绕过付费验证
- 报告直接在页面「4 · 总结提炼结果」区完整呈现，**不提供下载功能**

## 使用与隐私说明

- 无服务端、无账号体系，检索与提炼全部在访问者浏览器内完成；翻译时仅向公开翻译接口发送报道的公开标题与摘要文本，不含任何个人信息
- 检索历史、自动提炼开关与译文缓存保存在各自浏览器的 localStorage，不跨用户共享
- 免费翻译接口有配额，短时间高强度连续检索可能触发限流；此时自动重试与补译，仍失败会保留英文原文并如实标注，不会让页面卡住
- 中文话题若自动翻译失败，会按时间范围列出全部报道并提示手动填写英文检索词，避免结果为空
- GDELT 为公共免费接口，有 5 秒频率限制且限流响应在浏览器端表现为网络错误；已做节流与重试，失败会在概览显示「本次实时检索 0 篇」及原因
- 对 RSS 源站只读引用：尊重 ETag 缓存、本机留存快照、故障时降级不重试，不影响源站运行
- 仓库内无任何密钥或凭据
