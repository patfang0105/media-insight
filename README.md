# Media Insight · 境外媒体舆情检索与总结提炼

一个纯静态的舆情跟踪工具，托管于 GitHub Pages，无需服务器、无需安装。

**固定网址**：https://patfang0105.github.io/media-insight/

## 能做什么

- 输入中文或英文话题，自动译为英文关键词后检索境外媒体报道
- 数据源：自建 RSS 精选聚合站（国际媒体与智库，自带摘要）+ GDELT 全球媒体库
- 输出报道概览与热度、时间分布、来源排行、关键报道清单
- 勾选文章后点击「总结提炼」，直接生成中文摘译与观点提炼报告（内置免配置算法；也可在设置里填 LLM API 获得更高质量结果）
- 付费墙媒体逐条标注访问级别，仅使用其公开摘要，不绕过付费验证
- 报告可下载 Markdown / HTML

## 使用与隐私说明

- 无服务端、无账号体系，检索与提炼全部在访问者浏览器内完成
- 检索历史保存在各自浏览器的 localStorage，不跨用户共享
- 对 RSS 源站只读引用：尊重 ETag 缓存、本机留存快照、故障时降级不重试，不影响源站运行
- 仓库内无任何密钥或凭据
